# Back-to-Dashboard-Game-Developer-Android-iOS-Internship

Build 2D/3D mobile games for Android and iOS using Unity and C#.

## Projects

### Week 1 — Catch the Falling Objects
A 2D Python/Pygame prototype with falling objects, collision detection, score tracking, and lives.

Source: [week-1/catch-the-falling-objects](./week-1/catch-the-falling-objects)

### Week 2 — Platformer Level
A 2D platformer with jumping, moving platforms, collectible coins, a patrolling enemy, and a three-life system.

Source: [week-2/platformer](./week-2/platformer)

### Week 3 — Tilemap Adventure
A complete single-level 2D game with a tilemap, coins, patrol and chase enemies, a locked door, lives, and generated audio feedback.

Source: [week-3/tilemap-adventure](./week-3/tilemap-adventure)

### 🏆 Week 4 — Skybound Quest — Major Project
A complete 3-level 2D game prototype with enemies, power-ups, lives, persistent high score, generated sound effects, polished HUD/screens, and Android packaging configuration.

Source: [week-4/skybound-quest](./week-4/skybound-quest)

**Android note:** the repository includes a reproducible Chaquopy/Gradle Android build configuration. An APK/AAB must be compiled and signed with an Android SDK/NDK and release key; a binary is not claimed unless it has actually been built.
