# Week 3 — Tilemap Adventure

A complete single-level 2D game prototype built with **Python + Pygame**.

## Requirements

- Python 3.10+
- Pygame 2.5+

## Features

- **Tilemap level:** the complete level is represented by a grid of solid and empty tiles.
- **Patrol enemy:** moves back and forth across a fixed area.
- **Chase enemy:** follows the player's horizontal position when nearby.
- **Collectibles:** collect every coin in the level.
- **Door/finish point:** the door unlocks after all coins are collected.
- **Lives:** enemy contact costs one life and respawns the player.
- **Audio feedback:** coin collection, enemy hit, and level completion each have a generated sound effect. Audio is synthesized at runtime, so no binary audio assets are required.
- **Restart:** press R after winning or losing.
- **No external art or audio files:** everything is rendered/generated by the game.

## Run

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
python main.py
```

## Controls

| Action | Keys |
|---|---|
| Move | A/D or Left/Right |
| Jump | W / Up / Space |
| Restart | R |

## Gameplay

1. Explore the tilemap.
2. Collect all **7 coins**.
3. Avoid the red patrol enemy and purple chase enemy.
4. You have **3 lives**.
5. Once all coins are collected, reach the green door to finish the level.
